# H4.1: Detect Recursive Spec Functions

## Status: IN PROGRESS

## Goal
Add detection of recursive spec functions to the transpiler pipeline.

## Analysis

### What is a Recursive Function?
A spec function is recursive if its body contains a call to itself (direct recursion).
For our purposes, we focus on direct recursion only (not mutual recursion).

### Where to Add Detection
The detection should happen during parsing or annotation, so that:
1. AnnotatedFunction can include `is_recursive: bool`
2. The translator can decide how to handle recursive functions

### Implementation Approach

#### Option A: Parser-level detection
- Modify `SpecFunction` to include `is_recursive: bool`
- Detect self-calls during parsing

#### Option B: Post-parse analysis
- Analyze function body after parsing
- Add field to `AnnotatedFunction` in moder

**Decision: Option B** is simpler because:
- Parser already works
- Can analyze Expr tree for self-calls
- Easy to add to ModeAnalyzer

### Implementation Steps

1. Add `is_recursive: bool` field to `AnnotatedFunction` in `moder/mod.rs`
2. Add helper function to detect self-calls in expression tree
3. Call detection in `ModeAnalyzer::annotate()`
4. Add tests for recursive detection

### Code Changes

```rust
// In moder/mod.rs

impl AnnotatedFunction {
    // New field
    pub is_recursive: bool,
}

// New helper function
fn contains_self_call(expr: &Expr, func_name: &str) -> bool {
    match expr {
        Expr::Call { func, args } => {
            // Check if call is to self
            if func.segments.last() == Some(&func_name.to_string()) {
                return true;
            }
            // Check args recursively
            args.iter().any(|a| contains_self_call(a, func_name))
        }
        // Handle other expression types recursively
        ...
    }
}
```
