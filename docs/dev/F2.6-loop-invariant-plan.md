# F2.6: Loop Invariant Generation Plan

## Problem Analysis

The transpiler generates explicit for-loops for Verus verification but the invariants contain placeholder comments (`/* pred at i */`) instead of actual predicates.

### Current State

Generated code has incomplete invariants:

```rust
// In generate_any_loop (exists quantifier):
for p in iter:p_iter
invariant
    found ==> exists|i: int| 0 <= i < p_iter@.0 && /* pred at i */,
{ ... }

// In generate_all_loop (forall quantifier):
for io in iter:io_iter
invariant
    all_match <==> forall|i: int| 0 <= i < io_iter@.0 ==> /* pred at i */,
{ ... }
```

### Root Cause

The `generate_any_loop`, `generate_all_loop`, and `generate_chain_any_loop` functions receive the predicate as an `ExecExpr` but don't convert it to a string for use in invariants. The `expr_to_invariant_string` function exists but isn't being used.

### Affected Files

- `src/generated/RSL/proposer_gen.rs` - Line 242: `any` loop in `CProposerNominateOldValueAndSend2a`
- `src/generated/RSL/replica_gen.rs` - Lines 125, 389, 564: `all` loops in various functions

## Solution

### 1. Fix `generate_any_loop`

Convert the predicate to an invariant string and substitute `container_iter@.1[i]` for the loop variable:

```rust
fn generate_any_loop(
    &self,
    container: ExecExpr,
    var_name: &str,
    predicate: ExecExpr,
) -> ExecExpr {
    // Convert predicate to string for invariant
    let pred_str = self.expr_to_invariant_string(&predicate);
    // Replace variable reference with indexed access
    let indexed_pred = pred_str.replace(
        &format!("*{}", var_name),
        &format!("{}_iter@.1[i]", var_name)
    );

    // Generate proper invariant:
    // found ==> exists|i: int| 0 <= i < var_iter@.0 && indexed_pred
    let invariant = format!(
        "found ==> exists|i: int| 0 <= i < {}_iter@.0 && {}",
        var_name, indexed_pred
    );
    // ... rest of function
}
```
