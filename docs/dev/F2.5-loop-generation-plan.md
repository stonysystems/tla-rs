# F2.5: Loop-Based Code Generation Plan

## Problem Statement

The transpiler currently generates iterator patterns like:
```rust
container.iter().filter(|x| pred(x)).collect()
container.iter().any(|x| pred(x))
container.iter().all(|x| pred(x))
c1.iter().chain(c2.iter()).any(|x| pred(x))
```

These patterns don't verify well in Verus because:
1. Verus needs explicit loop invariants
2. Iterator closures are hard to reason about
3. Chain operations lose information about which container an element came from

## Proposed Solution

Convert iterator patterns to explicit loops with invariants:

### Pattern 1: `.iter().any(|x| pred(x))`
```rust
// Before
container.iter().any(|x| pred(x))

// After
{
    let mut found = false;
    for x in container.iter() {
        invariant
            found ==> exists|i: int| 0 <= i < idx && pred(container[i]@),
        {
            if pred(&x) {
                found = true;
                break;
            }
        }
    }
    found
}
```

### Pattern 2: `.iter().all(|x| pred(x))`
```rust
// Before
container.iter().all(|x| pred(x))

// After
{
    let mut all_match = true;
    for x in container.iter() {
        invariant
            all_match <==> forall|i: int| 0 <= i < idx ==> pred(container[i]@),
        {
            if !pred(&x) {
                all_match = false;
                break;
            }
        }
    }
    all_match
}
```

### Pattern 3: `.iter().filter(|x| pred(x)).collect()`
```rust
// Before
container.iter().filter(|x| pred(x)).collect()

// After
{
    let mut result = Vec::new();
    for x in container.iter() {
        invariant
            result@.len() <= idx,
            forall|i: int| 0 <= i < result@.len() ==>
                result@[i] in container@ && pred(result@[i]),
        {
            if pred(&x) {
                result.push(x.clone());
            }
        }
    }
    result
}
```

### Pattern 4: `.iter().chain(other.iter()).any(|x| pred(x))`
```rust
// Before
c1.iter().chain(c2.iter()).any(|x| pred(x))

// After
{
    let mut found = false;
    for x in c1.iter() {
        if pred(&x) {
            found = true;
            break;
        }
    }
    if !found {
        for x in c2.iter() {
            if pred(&x) {
                found = true;
                break;
            }
        }
    }
    found
}
```

## Implementation Steps

### Step 1: Add Config Option
- Add `generate_loops_instead_of_iterators: bool` to TranspilerConfig
- Default to false for backward compatibility

### Step 2: Detect Iterator Patterns
In `transform_expr()`, detect:
- `Expr::MethodCall { method: "any" | "all" | "filter" | "collect", ... }`
- Chain of `.iter()` calls

### Step 3: Generate Loop Code
Create new functions:
- `generate_any_loop(container, predicate, ctx)`
- `generate_all_loop(container, predicate, ctx)`
- `generate_filter_loop(container, predicate, ctx)`
- `generate_chain_any_loop(containers, predicate, ctx)`

### Step 4: Add Invariant Generation
Create invariant templates for each loop type.
Start with simple invariants, can enhance later.
