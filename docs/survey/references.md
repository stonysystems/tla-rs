# References

Normalized bibliography of all papers, repositories, tools, and resources cited in this survey.

## Format

Each reference includes:
- **ID**: Short identifier used throughout the survey (e.g., `[mendoza2024]`)
- **Full citation**: Authors, title, venue, year
- **URL**: Paper link (arXiv, DOI, publisher)
- **Repo**: Repository link (if available)
- **Type**: paper / repo / tool / benchmark / dataset
